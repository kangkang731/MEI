====================================================
               西藏双创服务平台 - 项目简述
====================================================

一、项目概况
----------------------------------------------------
项目名称：西藏双创服务平台（MEI-UI）
项目类型：Web 前端应用（B/S 架构）
技术栈：Vue 3 + Vite 8 + Element Plus + Vue Router 5 + Vue I18n + ECharts
开发工具：VS Code、Node.js 20/22

本项目是面向西藏自治区创新创业企业的综合服务平台，旨在为企业提供政策查询、
企业入驻、项目申报、成果展示、融资对接、人才招聘、在线咨询等一站式服务。

平台支持中文/藏文双语切换，页面设计融入西藏文化元素（如藏式条纹、藏式配色），
体现了民族地区特色。

主要功能模块：
  1. 首页（Home）—— 平台概览与导航入口
  2. 政策中心（Policy）—— 创业政策浏览与收藏
  3. 企业入驻（Enterprise Entry）—— 企业信息登记与提交
  4. 项目申报（Project Apply）—— 创业项目在线申报
  5. 成果展示（Achievement）—— 创业成果展示与详情查看
  6. 融资服务（Financing）—— 融资需求提交与记录查看
  7. 人才招聘（Talent）—— 求职登记与人才信息管理
  8. 在线咨询（Consultation）—— 用户问题咨询与回复
  9. 个人中心（Personal Center）—— 用户信息、企业、申报、融资、收藏等管理

后端技术栈推测基于若依（RuoYi）框架（API 路径 /system/user/profile 等），
前后端分离，通过 RESTful API 交互。

三、我的责任（前端开发）
----------------------------------------------------
作为前端开发工程师，本人负责以下核心工作：

  1. 项目搭建与工程化
     - 基于 Vue 3 + Vite 搭建前端工程
     - 配置 Vue Router 路由系统（含路由守卫、动态标题）
     - 集成 Element Plus 组件库并实现按需导入
     - 配置 Prettier 代码格式化规范

  2. 多语言国际化（i18n）
     - 实现中文/藏文双语切换功能（vue-i18n）
     - 编写藏文翻译文件（bo-CN.js），覆盖所有模块文案
     - Element Plus 组件文案同步国际化
     - 语言偏好持久化（localStorage）

  3. 核心页面开发
     - 个人中心（PersonalCenter）—— 最复杂的页面，包含：
       · 用户信息展示与编辑（头像上传、资料修改）
       · 企业信息管理（查看已入驻企业列表）
       · 项目申报记录（申报列表、状态展示）
       · 融资记录查看
       · 咨询记录管理（咨询列表、回复展示）
       · 政策收藏管理（收藏列表、取消收藏、跳转详情）
       · 求职登记功能（信息填写、简历上传、表单校验）
       · 登录状态检测与登录引导弹窗
     - 登录/注册页面
     - 政策列表与详情页面
     - 企业入驻表单页面
     - 项目申报表单页面
     - 成果展示与详情页面
     - 融资申请页面
     - 人才招聘页面
     - 在线咨询页面

  4. 接口联调与数据处理
     - 封装 Axios 请求工具（request.js），统一处理请求/响应
     - 对接若依框架用户认证接口（token 鉴权）
     - 对接业务 API：企业、申报、融资、咨询、收藏、求职等
     - 处理接口异常、错误提示、空状态展示

  5. UI/UX 设计实现
     - 实现西藏特色视觉风格（藏式条纹、配色、圆角卡片）
     - 响应式布局适配
     - 页面加载状态（v-loading）、骨架屏
     - 表单验证、操作确认弹窗、消息提示

  6. 代码质量保障
     - 使用 Vue 3 Composition API（<script setup>）
     - 组件化开发，保持代码可维护性
     - 路由懒加载优化首屏性能
     - 处理路由异常防止白屏
